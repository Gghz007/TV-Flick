# TV Flick

[English](README.md) · [Русский](README.ru.md) · [Polski](README.pl.md)

TV Flick — локальна бібліотека фільмів і серіалів для Windows та Android. Тут можна зберігати список перегляду, улюблене й прогрес за окремими серіями. Вхід через Google добровільний.

## Можливості

- **Shows / Movies.** Список перегляду показує наступну випущену серію та кількість інших доступних серій. Upcoming показує майбутні релізи.
- **Search.** Пошук, рекомендації, популярне й тренди за даними TMDB.
- **Profile.** Статистика переглядів, бібліотека, улюблене та фільтри за станом перегляду.
- **Плеєр.** MP4 і HLS із налаштованих джерел, вибір якості й озвучення, швидкість, мініплеєр і Auto MARK. Позначка в бібліотеці ставиться після досягнення 70% або завершення відео, якщо Auto MARK увімкнено.
- **Завантаження.** З картки можна вибрати озвучення та якість. Windows відкриває вікно збереження, Android пропонує сумісний завантажувач.
- **Резервні копії.** Відновлення з `.tvbackup` або JSON, експорт CSV і PDF. За бажанням можна підключити Google Drive і налаштувати AutoExport під час запуску.

## Установлення

[Збірки на GitHub Releases](https://github.com/Gghz007/TV-Flick/releases)

- **Windows x64.** Розпакуйте ZIP у папку, доступну для запису, і запустіть `TV Flick.exe`. Бібліотека зберігається поруч у `Local Database`.
- **Android 8.0+.** Відкрийте APK на телефоні.
