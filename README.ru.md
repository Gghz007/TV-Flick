# TV Flick

[English](README.md) · [Українська](README.uk.md) · [Polski](README.pl.md)

TV Flick — локальная библиотека фильмов и сериалов для Windows и Android. В ней хранятся список просмотра, избранное и прогресс отдельных серий. Вход через Google по желанию.

## Возможности

- **Shows / Movies.** Watch List показывает следующую вышедшую серию и количество остальных доступных. Upcoming показывает будущие релизы.
- **Search.** Поиск, рекомендации, популярное и тренды по данным TMDB.
- **Profile.** Статистика просмотров, библиотека, избранное и фильтры по статусу.
- **Плеер.** MP4 и HLS из подключённых источников, выбор качества и озвучки, скорость, мини-плеер и Auto MARK. При включённом Auto MARK серия или фильм отмечается в библиотеке при достижении 70% позиции или по завершении видео.
- **Скачивание.** Из карточки можно выбрать озвучку и качество. Windows открывает окно сохранения, Android предлагает совместимый загрузчик.
- **Бекапы.** Восстановление из `.tvbackup` или JSON, экспорт CSV и PDF. Можно подключить Google Drive и включить AutoExport при запуске.

## Установка

[Сборки на GitHub Releases](https://github.com/Gghz007/TV-Flick/releases)

- **Windows x64.** Распакуйте ZIP в папку с правом записи и запустите `TV Flick.exe`. Библиотека хранится рядом в `Local Database`.
- **Android 8.0+.** Откройте APK на телефоне.

[Скриншоты и сборка из исходников](README.md) · [Политика конфиденциальности](https://gghz007.github.io/TV-Flick/privacy.html) · [Условия использования](https://gghz007.github.io/TV-Flick/terms.html)
